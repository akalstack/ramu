# Provider logos

Local copies of the actual provider marks, in their own colors, used to identify integrations. Trademarks belong to their respective owners. A mark that is black on its own has a `-dark.svg` version for dark surfaces.

- **Claude**: [SVGL](https://svgl.app)'s Claude AI icon, in Anthropic's orange. The original branding is Anthropic's.
- **Codex / OpenAI**: `openai.svg` and `openai-dark.svg` from SVGL.
- **OpenCode**: `opencode-dark.svg` is [OpenCode's official square logo](https://github.com/anomalyco/opencode/blob/dev/packages/console/app/src/asset/brand/opencode-logo-dark-square.svg) (MIT); `opencode.svg` is its light square from SVGL.
- **Cursor**: `cursor.svg` and `cursor-dark.svg` from SVGL, Cursor's cube from its [brand asset archive](https://cursor.com/brand) with the color written into each path.
- **Antigravity**: full-color icon from the official [Google Antigravity press assets](https://antigravity.google/press).

After changing a file here, run `node apps/mobile/scripts/gen-assets.mjs`.
