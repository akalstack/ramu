# Code of Conduct

Ramu follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Be respectful, assume good intent, and keep discussion about the work.

Maintainers may edit or remove comments, and may block people who repeatedly break these rules. To report a problem privately, use **Security → Report a vulnerability** on GitHub and say that it concerns conduct.
