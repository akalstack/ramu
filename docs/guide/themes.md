# Appearance and themes

**Settings → Appearance** sets light, dark or match device, the language, fonts and reduced motion. Choices stay on this device.

## Themes

The gallery has Ramu Default, built-in themes (Graphite, Midnight, Forest, Rose, Sand, High contrast) and your own. Clicking one applies it at once.

- **Customize colors** edits both light and dark, with undo and a live preview of real app parts. Readability checks block unreadable combinations.
- The editor can ask the host's model for colors from a description or up to three reference images; **Another direction** and **Compare 3** try alternatives.
- Agents can offer a theme with **Preview theme**; nothing is kept until you choose **Keep theme**.
- Export a theme as a `.ramu-theme.json` file or JSON, and import one the same way.

The phone has the same built-in themes and your kept ones.
