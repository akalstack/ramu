# Diagnostics

**Settings → Background & updates → Keep local crash reports** is off by default. With it on, Ramu records a small amount of metadata about errors and crashes on this computer only; nothing is uploaded.

**Copy sanitized diagnostics** exports that metadata as JSON: platform, time, a category and an error type. It never contains messages, file names, prompts, code or credentials. **Clear diagnostics** removes it. Restart Ramu after turning the option on or off.
