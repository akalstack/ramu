# Ramu docs

## Guide

For people using Ramu.

- [Providers](guide/providers.md): set up Claude Code, Codex, OpenCode, Cursor or Antigravity.
- [Agents](guide/working-with-agents.md): models, fallback, helpers, custom agents and work across threads and hosts.
- [Home and Inbox](guide/inbox.md): what needs you, what is running, and what it uses.
- [Browser, computer use and test devices](guide/browser-and-computer.md): what agents can drive, and Float.
- [Goals](guide/goals.md): keep a thread working toward an objective across turns.
- [Background work](guide/background-work.md): threads, terminals and schedules that keep running with the window closed.
- [Memory and learning](guide/memory-and-learning.md): what carries over between threads.
- [Ramu account and settings backup](guide/account.md): optional free sign-in, end-to-end encrypted settings backups, and devices on the same account connecting to your hosts without a code.
- [Identities and moving settings](guide/identities.md): work and personal accounts picked per project, and settings copied between hosts.
- [Plugins](guide/plugins.md): add a service's skills, MCP servers, credential and CLI in one install, or build one.
- [Shipping an app](guide/shipping.md): from one sentence to a live app with CI, previews and uptime.
- [Deploying an app](guide/deploy.md): deploy to your own hosting account through the platform's plugin.
- [GitHub, GitLab, Bitbucket and Azure DevOps](guide/git-hosting.md): sign-ins, pull requests and reviews.
- [Editor](guide/editor.md): the file editor, Markdown and Mermaid, and moving files between hosts.
- [Artifacts](guide/artifacts.md): interactive documents agents publish, and what they may use.
- [Remote hosts](guide/remote-hosts.md): connect devices, run a headless server, start threads from a terminal.
- [Appearance and themes](guide/themes.md): light and dark, fonts, and built-in or custom themes.
- [Configuration](guide/configuration.md): `settings.json`, agents changing settings, and `ramu.json` team defaults.
- [Diagnostics](guide/diagnostics.md): local-only crash reports.
- [Mobile app](../apps/mobile/README.md).
