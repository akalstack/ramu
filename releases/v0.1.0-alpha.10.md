# Ramu v0.1.0-alpha.10

## Added

- Phone: **Connect your phone** in setup gets this computer ready for your phone with one button and shows a pairing QR code and code that renew themselves, then says when the phone is paired. A phone button in the sidebar and the **Connect a phone** command open the same code at any time.
- Phone: the pairing QR code opens in your phone's own camera. It opens Ramu, or the App Store or Google Play first when the app isn't installed yet.
- Phone app: until a computer is paired, a welcome screen offers **Scan QR code**, **Find a computer nearby**, **Sign in with your Ramu account**, or an address and code. A scan pairs straight away and says which computer it joined.

## Changed

- Remote access: **Pair a device…** is no longer disabled while devices aren't allowed; it offers **Allow devices on this network** in the same dialog.
- Phone app: pairing problems say what to do next, such as asking your computer for a new code, instead of showing the host's error.
- Antigravity runs only on the Antigravity CLI (`agy` 1.5 or newer). The older runtime and its **Harness helper path** setting are gone; choose **Update** or **Install runtime** if Antigravity stopped working.

## Downloads

Choose the installer matching your OS and CPU: macOS arm64 (Apple Silicon), macOS x64 (Intel), or Linux x64 or arm64 (.deb, .rpm, AppImage or ZIP). SHA256SUMS files accompany the downloads.

## Known limitations

Desktop alpha. macOS builds update themselves; Linux installs outside a package manager update by hand. Windows releases are not available yet. Agent providers require their own installation and authentication.
