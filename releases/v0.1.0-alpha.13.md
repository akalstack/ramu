# Ramu v0.1.0-alpha.13

A security release. Update every host, especially one reachable through a tunnel or paired with another host.

## Security

- Goals: only you can set a goal's `verify:` command. `/goal` in a message from a paired host, a terminal or another agent is now sent as plain text, so none of them can make the host run a command without approval.
- Remote access: pairing without a code is refused through a tunnel address (Ramu Link, quick tunnel, Tailscale Funnel, ngrok or your own). A device away from home pairs with a code or through your Ramu account, so nobody on the internet can put a pairing request in front of you.
- Remote access: behind Tailscale Funnel, ngrok or your own proxy, a visitor can no longer choose the address Ramu limits retries by and shows in pairing requests.
- Plugins: a signed-in plugin CLI's own home folder is private to your account. On a Linux computer with other accounts, Ramu refuses a folder another account made or can open.
- Files: copying or importing files never copies Ramu's own data folder, or a folder that holds it.
- Plugins: another web page can no longer cancel a plugin sign-in in progress.
- Ramu Link: signing out stops new tunnel requests straight away, and each address has a limit on how many link calls it can make.
- Dependencies: updated `image-size`, `seroval`, `minimatch` and `diff` to their patched releases.

## Downloads

Choose the installer matching your OS and CPU: macOS arm64 (Apple Silicon), macOS x64 (Intel), or Linux x64 or arm64 (.deb, .rpm, AppImage or ZIP). SHA256SUMS files accompany the downloads.

## Known limitations

Desktop alpha. macOS builds update themselves; Linux installs outside a package manager update by hand. Windows releases are not available yet. Agent providers require their own installation and authentication. Ramu Link traffic passes through Cloudflare; every call still needs a paired device.
