# Ramu v0.1.0-alpha.25

## Changed

- Sending holds still. A new thread's first message lands where the thread keeps it and the thread opens in place; a follow-up lands where it stays, with its date shown at once, and the reply grows below it instead of swapping places with the status line.
- A running tool group no longer shrinks under you while it works, so the transcript stops jumping up and down. Each group settles once when it finishes, even while the turn goes on.
- The phone shows thinking like the desktop: folded to its newest line while it streams, **Thought for 4s** once done, and the full thought when opened.
- Pull request lists load faster: the open and closed lists share one read per repository, repositories are read in parallel, and Refresh asks once.
- **Settings → Identities** opens without waiting on the GitHub CLI.
- The `ramu` terminal command finds Ramu again after a reinstall in either Applications folder, and says how to get it when the app is gone.
- Phone tab headers stay transparent on iOS point releases instead of turning into a grey bar that hides the top of the list, and Live Activities turn on there too.

## Downloads

Choose the installer matching your OS and CPU: macOS arm64 (Apple Silicon), macOS x64 (Intel), or Linux x64 or arm64 (.deb, .rpm, AppImage or ZIP). SHA256SUMS files accompany the downloads.

## Known limitations

Desktop alpha. macOS builds update themselves; Linux installs outside a package manager update by hand. Windows releases are not available yet. Agent providers require their own installation and authentication. Ramu Link traffic passes through Cloudflare; every call still needs a paired device.
