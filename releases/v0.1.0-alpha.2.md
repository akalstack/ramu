# Ramu v0.1.0-alpha.2

## Fixed

- macOS: Ramu opens again. On first launch, macOS reported "Ramu is damaged and can't be opened" and the app stopped with "Background service could not start". The copy of the app that runs the background service now keeps its code signature.
- Linux: the background service no longer depends on the AppImage mount it started from.

## Downloads

Choose the installer matching your OS and CPU: macOS arm64 (Apple Silicon), macOS x64 (Intel), or Linux x64 or arm64 (.deb, .rpm, AppImage or ZIP). SHA256SUMS files accompany the downloads.

## Known limitations

Desktop alpha. Updates are installed by hand. Windows releases are not available yet. Agent providers require their own installation and authentication.
