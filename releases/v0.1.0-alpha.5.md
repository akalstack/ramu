# Ramu v0.1.0-alpha.5

## Fixed

- Settings: after an app update, the background service row no longer says "Matches the installed app" beside an older version number. When the service runs the same code but started under an earlier release, it says so and shows the older version until the service next restarts. Restart app & service is still offered only when the service code differs.

## Downloads

Choose the installer matching your OS and CPU: macOS arm64 (Apple Silicon), macOS x64 (Intel), or Linux x64 or arm64 (.deb, .rpm, AppImage or ZIP). SHA256SUMS files accompany the downloads.

## Known limitations

Desktop alpha. Linux installs are told about new releases and installed by hand. Windows releases are not available yet. Agent providers require their own installation and authentication.
