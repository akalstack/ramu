# Ramu v0.1.0-alpha.1

First desktop alpha of Ramu, an MIT-licensed workspace for coding with agents.

## Included

- Projects with multiple repositories, agent chats, an editor, terminals, and Git.
- Claude Code, Codex, OpenCode, Cursor, and Antigravity through installed runtimes.
- Recorded diffs, review comments, and file restoration with conflict checks.
- Background chats, goals, schedules, restart recovery, and daily recaps.
- Helper agents, asides, shared memory, optional advice, and usage-limit fallback.
- Remote access: run the workspace service on one computer, pair other desktops with a one-time code, and revoke devices at any time.
- English and Bahasa Indonesia.

## Installation

Release targets are macOS arm64, macOS x64, and Linux x64. Use the matching installer and accompanying SHA-256 checksum. Available assets are listed on GitHub Releases.

For source builds, see the [README](../README.md).

## Limitations

- macOS CI builds are unsigned and not notarized. Automatic installation requires a signed app.
- Update checks exclude prereleases. Install alpha updates manually.
- Linux packaged GUI validation is pending; Windows downloads are not provided.
- Providers need their own installation, authentication, and model access.
- Background work requires an awake computer.
- Project search and replace require ripgrep (`rg`) installed on the computer (`brew install ripgrep` or `apt install ripgrep`).
- The mobile companion app is not part of this release.

## Validation

Checked on 2026-10-15 against the current monorepo:

- `pnpm check` passed: workspace type checks, all unit suites (825 tests passed, 16 skipped; the server suite passed repeatedly with default parallel workers), three release-script tests, and desktop/server builds.
- The full simulated desktop journey (`pnpm test:e2e`) passed on macOS, including live tool output, connector input, reviews, undo, async questions, account profiles, settings, and service restart recovery, with no renderer errors.
- Fixed: a newly added provider account was missing from the account picker until settings were saved, so the picker showed its raw ID.

Live provider calls, packaged installers, signing, and notarization were not verified for this release.
