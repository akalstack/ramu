# Ramu v0.1.0-alpha.1

The first public alpha of Ramu, the free, MIT-licensed workspace where your coding agents build an app, put it online and keep it running, on desktop and phone.

## Included

- Projects with several repositories, agent threads, a Monaco editor, split terminals, Git, worktrees and review with recorded diffs and selective undo.
- Claude Code, Codex, OpenCode, Cursor and Antigravity through their own installed runtimes and your own logins. Ranked fallback moves a thread to the next provider at a usage limit and back again.
- Goals that keep working across turns until their checks pass, background threads, schedules, recaps and restart recovery.
- Helpers on any provider, second opinions, shared memory and skills, custom agents, and Shared MCP tools with per-thread approval.
- Artifacts: apps, docs, decks, diagrams, dashboards, designs and short videos, exported to Word, PowerPoint, PDF or MP4.
- Shipping: new projects from one sentence, deploys through each platform's own plugin (Vercel, Netlify, Railway, Cloudflare, Fly.io) with production waiting for your OK, **Set up CI** and uptime incidents.
- GitHub, GitLab, Bitbucket and Azure DevOps pull requests and reviews.
- Built-in browser, computer use on macOS, and iOS Simulator and Android emulator testing.
- Remote hosts: pair other desktops and phones over your LAN, VPN, SSH or your own tunnel, run a headless server with the `ramu` CLI, and continue a thread on another host.
- An optional free Ramu account for end-to-end encrypted settings backups and finding your hosts. Nothing else needs an account.
- English and Bahasa Indonesia.

## Downloads

Choose the installer for your system and check it against the matching `SHA256SUMS` file:

| System | Files |
| --- | --- |
| macOS, Apple Silicon | `arm64` `.dmg` or ZIP |
| macOS, Intel | `x64` `.dmg` or ZIP |
| Linux x64 and arm64 | `.deb`, `.rpm`, AppImage or ZIP |

The AppImage needs FUSE 2: `sudo apt install libfuse2t64` on Ubuntu 24.04 and later, `libfuse2` on 22.04.

The phone app for iOS and Android comes from the App Store and Google Play, or can be built from source ([mobile README](../apps/mobile/README.md)). Pair it from **Settings → Remote access** on the desktop.

## Known limitations

- macOS builds are not notarized yet. The first time you open Ramu, macOS says it can't check it for malicious software: choose **Done**, then **System Settings → Privacy & Security → Open Anyway**. Updates are installed by hand from GitHub Releases; Settings links to each new release.
- Windows is not available yet.
- Computer use works on macOS only.
- Each provider needs its own installation, sign-in and model access. Some features depend on the provider.
- Agents run on your computer, so background work needs it awake and online. **Keep host awake** helps on macOS and Linux.
