# Ramu v0.1.0-alpha.1

First public alpha of Ramu, an MIT-licensed desktop workspace for coding alongside agents.

## Highlights

- Group repositories into projects and keep agent chats, files, terminals, and Git in one workspace.
- Connect installed Claude Code, Codex, OpenCode, Cursor, and Antigravity runtimes, with model selection and provider-specific capabilities.
- Review recorded changes, send file and line comments, and preview file restoration with conflict checks.
- Keep chats and schedules running through the local background service, with goals, restart recovery, and a daily recap.
- Use helper agents, read-only asides, optional cross-provider advice, and configurable usage-limit fallback.
- Customize the workspace and use English or Bahasa Indonesia.

## Installation

The release workflow targets macOS Apple Silicon (arm64), macOS Intel (x64), and Linux x64. Choose the matching installer and verify it against the accompanying SHA-256 checksum file. These targets describe the workflow; installers are available only after its successful build.

To run from source, use Node.js 24 and pnpm 11.21.0, then run `pnpm install --frozen-lockfile` and `pnpm dev`. See the [README](../README.md) for prerequisites and provider setup.

## Known limitations

- This is an alpha; workflows and provider compatibility are still being validated.
- Automated macOS builds are unsigned and not notarized. Automatic restart-to-install requires a signed macOS app; unsigned builds require manual installation.
- In-app update checks exclude prereleases, including this alpha. Download alpha updates manually.
- Linux packaged GUI validation is pending. Windows downloads are not included in the release workflow.
- Providers require their own installation, authentication, and model access. Simulated integration tests do not verify live provider authentication or model calls.
- Background work requires the computer to remain awake. Packaged login startup needs installation-level validation.
- Remote computers and mobile access are proposed work, not included in this release.
