# Ramu v0.1.0-alpha.24

## Changed

- Tools are suggested while a thread runs. The agent can suggest a plugin, skill or MCP server from Ramu's catalogs, and a link to a known service or the project's stack can suggest one too. A card in the thread turns it on for the project or everywhere, or hides it; nothing is turned on without you. **Settings → Threads → Suggest tools while threads run** turns the cards off.
- Model lists are searchable: type any words in any order, with clean names grouped by provider and route. The phone's model sheet shows the same names.
- **Connect a phone or computer** is simpler: the code first, Full access or View only beside it, Copy link and Copy code, and how phones reach this computer with a way to change it.
- A skill in the message box shows what it does and where its SKILL.md lives, and opens it or its folder.
- Images, speech, music and sound effects can come from a plugin's background jobs, with progress, clear refusals, credits and time limits, as video and 3D already could. A plugin's companion counts as installed under either of its names.
- Development builds run as Ramu Dev with their own data and keychain item, so they no longer ask for the keychain password.
- Setup asks for the language only on its first step.

## Downloads

Choose the installer matching your OS and CPU: macOS arm64 (Apple Silicon), macOS x64 (Intel), or Linux x64 or arm64 (.deb, .rpm, AppImage or ZIP). SHA256SUMS files accompany the downloads.

## Known limitations

Desktop alpha. macOS builds update themselves; Linux installs outside a package manager update by hand. Windows releases are not available yet. Agent providers require their own installation and authentication. Ramu Link traffic passes through Cloudflare; every call still needs a paired device.
