# Ramu v0.1.0-alpha.17

## Added

- Ramu Link for three computers: one Ramu account now keeps a free address for up to three computers, each its own. Your phones and the other devices you connect from don't count, and any number of them can connect through a link (the 10 GB a month is the only limit). A fourth computer lists the three that hold one, each with **Give back and use here**, so the link moves without walking to the other computer. See [Ramu Link](https://github.com/akalstack/ramu/blob/main/docs/guide/remote-hosts.md#ramu-link).
- About: **Settings → About** shows the version with **What's new**, the host's updates, the documentation, **Report a problem** (a GitHub issue with the version and system filled in), **Share an idea**, the source code, local diagnostics and the license. Updates and diagnostics moved here, so **Background & updates** is now **Background**.
- A smaller download: the installers no longer carry their own copies of Claude Code (about 350 MB, over half the download). Ramu runs the Claude Code you install, as it already did, and search uses the ripgrep inside it when `rg` isn't installed.
- The phone can delete your Ramu account from **Settings → Ramu account**, after a confirmation.
- The phone's **About** lists the same links: what's new, documentation, reporting a problem and the source code.

## Fixed

- The phone's **About** no longer shows a meaningless "Data: Live workspace" row.

## Downloads

Choose the installer matching your OS and CPU: macOS arm64 (Apple Silicon), macOS x64 (Intel), or Linux x64 or arm64 (.deb, .rpm, AppImage or ZIP). SHA256SUMS files accompany the downloads.

## Known limitations

Desktop alpha. macOS builds update themselves; Linux installs outside a package manager update by hand. Windows releases are not available yet. Agent providers require their own installation and authentication. Ramu Link traffic passes through Cloudflare; every call still needs a paired device.
