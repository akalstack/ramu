# Ramu v0.1.0-alpha.4

## Fixed

- Git: commit titles stay readable in a narrow panel. A commit shows one branch or tag label and a count for the rest, the label shrinks before the title does, and the list no longer scrolls sideways. The pull request link above it fits the panel too.
- Threads: the latest tool group no longer flashes a quick left-to-right highlight each time one tool ends and the next starts, or when you open it. The highlight waits until the work has settled and plays more slowly, on desktop and on the phone.

## Downloads

Choose the installer matching your OS and CPU: macOS arm64 (Apple Silicon), macOS x64 (Intel), or Linux x64 or arm64 (.deb, .rpm, AppImage or ZIP). SHA256SUMS files accompany the downloads.

## Known limitations

Desktop alpha. Linux installs are told about new releases and installed by hand. Windows releases are not available yet. Agent providers require their own installation and authentication.
