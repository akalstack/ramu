# Ramu v0.1.0-alpha.21

## Added

- **Cmd-click** (Ctrl-click elsewhere) on a link opens it in your own browser, whatever clicked links do by default.
- When Ramu needs a macOS permission, it says why and offers a button to the exact **Privacy & Security** page, then **Check again**. Importing sign-ins uses it when macOS blocks Ramu from reading a browser's data, instead of reporting that no profiles were found.

## Changed

- Answers are easier to read: paragraphs, lists and headings stop at about 72 characters a line, while code blocks and tables keep the full width. Inline code is smaller and quieter, and a short name such as `--primary-light` no longer breaks at its hyphen.
- The Brief shows one row per thread, its most urgent reason with "+N more" for the rest, and the Inbox badge counts threads. A thread still working, or already asking for something, keeps its recaps until it settles, and Recaps keeps one recent recap per thread.
- Learning saves automatically by default on new installs. With **Ask me first**, each review is titled by its thread, says what it would save, and shows the proposal as formatted text.
- Safari says plainly that importing its sign-ins isn't available yet.

## Fixed

- Pull request links no longer seem stuck while Ramu checks whether it lists them; with no quick answer they open as ordinary links.
- A running command in an open tool group shimmers across what shows, not across text hidden past the edge, on the desktop and the phone.
- Inline actions such as **Why?** under an approval keep to the line of text instead of turning into a tinted box.
- The import sign-ins card's rows join into one card again.

## Downloads

Choose the installer matching your OS and CPU: macOS arm64 (Apple Silicon), macOS x64 (Intel), or Linux x64 or arm64 (.deb, .rpm, AppImage or ZIP). SHA256SUMS files accompany the downloads.

## Known limitations

Desktop alpha. macOS builds update themselves; Linux installs outside a package manager update by hand. Windows releases are not available yet. Agent providers require their own installation and authentication. Ramu Link traffic passes through Cloudflare; every call still needs a paired device.
