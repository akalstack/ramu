# Ramu v0.1.0-alpha.6

## Fixed

- OpenCode: a thread on OpenCode 1 no longer fails with `Missing key at ["prompt"]`. Ramu supports OpenCode 2, so the thread now stops with a message that says to update, and the card in **Settings → Providers** offers **Update**, which runs `opencode upgrade --major` (plain `upgrade` stays on OpenCode 1). This replaces OpenCode 1 with 2.
- Chat: a command that finishes at once no longer flashes the working shimmer on its label. The shimmer starts only after a call has run for about half a second, on desktop and phone.
- Chat: a thought no longer repeats "Thinking" beside its brain icon. The row shows the icon and the thought itself, with "Thought for 4s" kept once it took a while.

## Changed

- Approvals: when Full access still asks before a command, the card says so with a **Why?** that opens the specific reason, what Full access skips, and why Allow once covers only that request. The reason no longer sits in the command text. This is on desktop and phone.

## Downloads

Choose the installer matching your OS and CPU: macOS arm64 (Apple Silicon), macOS x64 (Intel), or Linux x64 or arm64 (.deb, .rpm, AppImage or ZIP). SHA256SUMS files accompany the downloads.

## Known limitations

Desktop alpha. Updates are installed by hand. Windows releases are not available yet. Agent providers require their own installation and authentication.
