# Ramu v1.1.0-beta.5

## Added

- **Sign in to an MCP server from Ramu.** A server that shows **Needs authentication** in a thread's MCP status has **Sign in**, on the desktop and the phone, for Claude Code and Codex threads. It opens the server's sign-in page, and the server turns ready once you allow access. From the phone or another computer, paste the address the browser ended on and press **Finish**. Before, **Reconnect** only answered "Server status: needs-auth".
- Ask the agent to save something as a skill ("save this as a skill"): it shows the name, when to use it and the instructions, and adds the skill once you approve. It is yours, as if written in **Customize → Skills**, and learning never changes it.

## Changed

- **Dismiss** is on every question the agent asks, on the desktop and the phone, including one it waits on. The agent is told you dismissed it without answering and goes on with what does not depend on it.
- **Finished threads load a page at a time.** A host sends its open threads and the newest 25 finished ones, so the thread list stays small on the phone and over a slow link. **Done** still counts every finished thread, and **Show N more** loads the next 25, on the desktop and the phone. A finished thread open in a tab stays loaded. The approach follows T3 Code's older settled threads.
- **Daily recaps are gone.** They repeated what Inbox's **Brief** and **Done** already show from the threads themselves, and spent model tokens to do it. The **Daily recaps** settings, the `/recap` command and the phone's daily recap notification went with them.
- An agent waits on a long command Ramu moved to the background, and stops a run before starting it again.
- Beta and release candidate versions appear on GitHub as releases; only alpha versions carry the pre-release label. Updates are unchanged: an install follows its own channel and anything more settled.

## Fixed

- The chat keeps following the agent's output until you scroll away yourself. Steps folding above while a large block arrived below could move the view up, and it then stayed there.
- An answer sent while the agent is working waits as **Answered 1 question**, the line it becomes once sent, instead of a bubble with the note the agent reads.
- **Cancel** and **Sync anyway** in **Push to a protected branch?** answer again. Neither did, so the sync never ended and **Commit & Push** kept spinning with every Git control in the thread disabled. Waiting for a branch switch and confirming **Done** on a thread had the same fault.
- Signing in to a provider opens one sign-in page. Claude Code, Codex, GitHub and GitLab open the browser themselves on this computer, so Ramu no longer opens the same link a second time; on another host Ramu still opens it here. The sign-in terminal stays open until the login changes or the command finishes, instead of closing after a few seconds when an account was already signed in.
- In an answered question card, a question that folds open has room around its text when pointed at, and a settings title found by search or a link is highlighted with room around it.

## Downloads

Choose the installer matching your OS and CPU: macOS arm64 (Apple Silicon), macOS x64 (Intel), or Linux x64 or arm64 (.deb, .rpm, AppImage or ZIP). SHA256SUMS files accompany the downloads.

## Known limitations

macOS builds update themselves; Linux installs outside a package manager update by hand. Windows releases are not available yet. Agent providers require their own installation and authentication.
