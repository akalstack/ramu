# Ramu v1.1.0-beta.3

## Added

- **Manage a host's devices from your phone or another computer.** A device with full access and the host's **settings changes** permission lists the host's devices, renames and removes them, removes all the others, shows a code to connect a new device with **Full access** or **View only**, and answers nearby devices asking to pair. On the desktop it is **Settings → Devices & access** with another host selected; on the phone, **Settings → Paired computers → Devices**. Without the permission, **Request access** asks the person at the host. Each change shows on the host as a notification and under **Changes from other devices**.

## Changed

- **Settings → Devices & access** replaces Remote access with one page in the order you set a host up: **Reachable from** (This computer, This network or Anywhere) first, with ports, tunnels, Stay reachable and Keep awake under **Advanced**; then **Connect a device**, the device list with **Remove** and **Remove others**, devices on your Ramu account, **Linked hosts** and the hosts you use. Per-device permissions move under **Limit this device**. Your settings carry over unchanged.
- Plan usage recognises one login across hosts by the provider's account id, then by email.
- Quitting with **Keep running when Ramu closes** off hides the window at once and stops the service out of sight. **Keep running** and **Start at login** wait for **Save changes** like the rest of Settings.
- The same error or notice back to back shows once with a count (×3), on the desktop and the phone, and goal and sub-agent rows say only what changed.
- Setup chooses the default agent first and asks for model and effort on one step; sign-in opens its page and finishes by itself.
- Replies use the full column, with tighter paragraphs, larger headings and roomier numbered lists.

## Fixed

- **A host with many saved change reviews no longer writes to disk constantly.** Listing reviews sorted every review into a temporary file on each refresh, tens of MB at a time, which kept a busy host loaded until its windows lost their connection. Opening Ramu adds the missing index once.
- The window layout saves while **Artifacts**, **Pull requests** or **Customize** is open, instead of failing with "Sidebar is not one of the allowed options".
- A thread at a usage limit no longer piles up limit errors while it waits: retries back off to an hour, following the provider's stated reset.
- Computer and browser tools keep working on every turn of a thread.
- A finished goal is no longer repeated in every prompt, and only a request in words starts a goal.
- The notifications panel stays on the bell, and **New thread** lines up with the list.
- On the phone: one limit message instead of four, **Scroll to latest** lands at the end, inline code is padded, and the Live Activity shows one combined state.

## Downloads

Choose the installer matching your OS and CPU: macOS arm64 (Apple Silicon), macOS x64 (Intel), or Linux x64 or arm64 (.deb, .rpm, AppImage or ZIP). SHA256SUMS files accompany the downloads.

## Known limitations

Desktop beta. macOS builds update themselves; Linux installs outside a package manager update by hand. Windows releases are not available yet. Agent providers require their own installation and authentication. Ramu Link traffic passes through Cloudflare; every call still needs a paired device. A database from this release opens only in this release or later.
