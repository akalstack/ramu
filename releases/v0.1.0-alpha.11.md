# Ramu v0.1.0-alpha.11

## Added

- Phone app: messages show the terminal output, artifacts and review comments sent with them, as on the desktop.
- Phone app: **Add screen to chat** in a thread's terminal puts what the terminal shows above the message box; it goes to the agent with your next message.
- Phone app: **Run in background** on a running Claude command lets the agent carry on.
- Phone app: dashboards take a refresh interval and a date range from the artifact's menu.
- Phone app: when a usage limit would move the next message to another provider, a chip says so above the message box, with **Keep this provider** for the message or the thread.
- Phone app: a repository with no remote can be published to GitHub from Source control.
- Phone app: queued messages can move up and down.
- Agents: a secret card can open the page that gives the value, such as a token settings page.

## Changed

- Deploys: agents choose a hosting platform and install its plugin or CLI themselves. The Deploy sheet is now **Live app…** in the project menu, with the latest deploy, the live address and its uptime, the production database, CI and **Run on this computer**. Production deploys still ask first in every access mode.

## Downloads

Choose the installer matching your OS and CPU: macOS arm64 (Apple Silicon), macOS x64 (Intel), or Linux x64 or arm64 (.deb, .rpm, AppImage or ZIP). SHA256SUMS files accompany the downloads.

## Known limitations

Desktop alpha. macOS builds update themselves; Linux installs outside a package manager update by hand. Windows releases are not available yet. Agent providers require their own installation and authentication.
