# Ramu v0.1.0-alpha.19

## Added

- Live work as one row of chips above the message box: **Agents**, **Browser**, **Computer**, **Servers**, **Terminals**, **Goal** and **Queued**. A chip opens its card above the row, one at a time, and chips that don't fit move into **⋯ +N**. **Auto-resume** sits beside the model and access pickers until a limit is near.
- Marking a thread done gives back what it holds: running helpers and background commands (and the servers they run) stop, and computer use, browser tabs, a test device and file watching are released. When something is still running, desktop and phone ask first and list what will stop.
- Starting from Home opens the new thread right away with your message and **Starting the agent…**. **Auto** still picks the project on Home first.

## Changed

- A message steered into a running turn stays part of it, on desktop and phone: one timer and one **Worked for** with the whole turn's time, and **Continued for** under each steer for the work after it. A turn folds only once it has finished, and a stopped turn reads **Stopped after**.
- A running tool group keeps its latest thought in view until it settles, and an opened thought is titled **Thought**.
- The working shimmer moves at a steady pace, so long command labels no longer streak across.
- A new thread whose first message waits on another thread in the same checkout shows it as its opening message, with **Waiting for "…" in the same checkout** and **Open thread**. **Send now** is no longer offered there, since only one thread works in a checkout at a time.

## Fixed

- Phone: the Settings header on Android no longer crowds its title against the host chip; notices and toasts have a visible background again; long approval titles wrap inside their card; the chat header has no empty band under it; browser and computer chips are labelled, servers have their own icon, and finished helpers read "N agents" instead of "0 active agents".

## Downloads

Choose the installer matching your OS and CPU: macOS arm64 (Apple Silicon), macOS x64 (Intel), or Linux x64 or arm64 (.deb, .rpm, AppImage or ZIP). SHA256SUMS files accompany the downloads.

## Known limitations

Desktop alpha. macOS builds update themselves; Linux installs outside a package manager update by hand. Windows releases are not available yet. Agent providers require their own installation and authentication. Ramu Link traffic passes through Cloudflare; every call still needs a paired device.
