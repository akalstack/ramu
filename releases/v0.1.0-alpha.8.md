# Ramu v0.1.0-alpha.8

## Added

- Antigravity: Ramu runs on Google's Antigravity CLI. An `agy` you installed (1.5 or newer) is used as it is, with nothing to download, and **Update** runs its own `agy update`, which also brings an older `agy` up to 1.5. Without one, **Install runtime** downloads the CLI (about 85 MB instead of 300 MB), checks Google's SHA-512 and continues a dropped or stalled download where it stopped. Each login keeps its sign-in in its own file, never in the OS keychain.
- Antigravity: **Login** with a Google account or Gemini Enterprise opens Google's page in the browser of the device you are using; allow access there and paste the code it shows into Ramu.
- Terminal: web addresses, file paths (with their line, such as `src/app.ts:12:3`) and OSC 8 hyperlinks in terminal output are links. A click opens pages in the browser you chose and files in the editor at their line; on the phone, a tap opens the page in the system browser or the file. Paths become links only once the host finds the file, and links wrapped across rows count as one.
- Terminal: select lines and click **Add to chat** in the terminal's corner, or right-click and choose **Add selection to chat**, to show an agent what the terminal printed. With nothing selected, **Add screen to chat** takes the rows on screen. The output waits above the message box as a chip naming the terminal and its lines. Click it to check the text, or × to take it off. It goes to the agent with your next message, and you can send it without typing anything. A project's own terminal starts **New chat** with the output in the box.
- Agents: agents can read your terminals in the thread themselves, so "fix the error in my terminal" works without pasting. They read the recent output as plain text, never type into your terminals, and values that look like secrets are redacted.

## Changed

- Antigravity: a Google sign-in made with the earlier runtime has to be made once more after updating; API keys carry over. A runtime Ramu downloaded earlier keeps working until you update it.

## Downloads

Choose the installer matching your OS and CPU: macOS arm64 (Apple Silicon), macOS x64 (Intel), or Linux x64 or arm64 (.deb, .rpm, AppImage or ZIP). SHA256SUMS files accompany the downloads.

## Known limitations

Desktop alpha. Updates are installed by hand. Windows releases are not available yet. Agent providers require their own installation and authentication.
