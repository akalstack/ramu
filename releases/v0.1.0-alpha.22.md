# Ramu v0.1.0-alpha.22

## Changed

- Opening a Brief row goes where its next step is: an approval or question scrolls to the request, a pull request opens its review, and a recap's decision opens the thread at the turn it is about. A failure opens its thread, which ends on the error with **Retry**.
- Recaps live on their threads. The Recaps tab is gone: in **Completed**, each finished thread's row says what it did, from its newest recap, and the daily recap's state and refresh sit at the top. Recaps that ask for a decision stay in the Brief. A recap notification opens Completed.

## Downloads

Choose the installer matching your OS and CPU: macOS arm64 (Apple Silicon), macOS x64 (Intel), or Linux x64 or arm64 (.deb, .rpm, AppImage or ZIP). SHA256SUMS files accompany the downloads.

## Known limitations

Desktop alpha. macOS builds update themselves; Linux installs outside a package manager update by hand. Windows releases are not available yet. Agent providers require their own installation and authentication. Ramu Link traffic passes through Cloudflare; every call still needs a paired device.
