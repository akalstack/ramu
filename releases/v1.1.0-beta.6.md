# Ramu v1.1.0-beta.6

## Added

- **Choose the model for Ramu's own work.** Titles, branch names, pull request text, summaries, asides and the rest of Ramu's own work can run on the default model, **Same as thread** (the thread's model and login), or a model you pick with its account, on the desktop and the phone. A new thread's branch is named with the model the thread will run on.
- **A goal's turn limit for one thread.** Open the goal on the desktop or the phone and change **Turn limit for this goal**; Settings keep the limit every other goal starts with.
- **Paste a picture or file into the phone's message box.** The text field's own **Paste** attaches what you copied, on iOS and on Android 12 and later.
- **Stop idle agents from Resources.** Resources offers **Stop N idle agents** with the memory it frees, on the desktop and the phone. Each starts again with its thread's next message; servers and terminals keep running.
- **A host low on memory cleans up by itself.** After two low readings in a row it stops the agents of threads idle ten minutes or more, never one whose goal carries on or that has messages queued, and the Brief says what it freed.
- **Build daemons no longer pile up.** Gradle, Kotlin, Maven, Bazel, Nx, Turborepo and similar daemons an agent leaves behind show as one **Build daemons** line in Resources instead of filling **Servers**. Ramu stops them once the thread and the daemon have rested ten minutes, so a long build is never cut off.
- New thread says when other threads are working in the current checkout, or left uncommitted changes there, and offers **Use a new worktree**.
- Pull down to refresh a thread and the thread list on the phone.
- A working thread shows how long its turn has run: in minutes on the phone's thread row, and as **Working for** in the desktop's hover card.
- Importing sign-ins from a browser can search the websites and select all of them, or all the search shows.

## Changed

- **Notifications follow the device you are using.** While the phone app is open it shows its own banners, so hosts send it no push and desktops raise no system notification; while you use the desktop, the phone stays quiet.
- **The phone answers an agent's question in a sheet** over the message box, opening it once by itself and sending separate questions one at a time.
- **A new thread starts on the project's default checkout**, even from a thread in a worktree, and the checkout menu no longer has **Use default**.
- The desktop sidebar shows a thread's status left of its title, as the phone and Activity do, with its age on the right.
- **Devices & access** shows how the host is reached as one card, with the unencrypted network warning in the warning colour.
- The phone's working shimmer is the desktop's soft sweep, and working dots pulse together on both.
- The row of chips above the message box keeps its height when empty, so a chip appearing or going never moves the conversation.
- Syncing shows as a floating pill on the phone and the desktop, so the list and the transcript never move for it.
- An answered question shows the question and the answer chosen.
- At a usage limit the model chip says **Limit**, and the limit note holds the one **Auto-resume** control.
- Marking a thread done also closes its browser tabs and stops servers it left running; its confirmation lists them.
- A running turn's **Working for** line is a plain timer; the working line at the end of the turn is the one that shimmers.
- List items in a reply have their full spacing on the desktop, as on the phone.
- The phone's activity row keeps each item as its own pill and folds only the overflow into **N more**.
- A completed goal reads as one line on the phone, with its objective folded below.
- The phone checks its hosts once a minute instead of every 20 seconds, so an open app uses less battery.

## Fixed

- The desktop transcript scrolls with the wheel again while it follows the agent.
- The phone's transcript holds still while the agent works: a row you opened stays where it is, and the end is kept without gliding.
- Settings keeps the host picker usable after switching to a host it had not read yet.
- The status bar's checkout menu shows one check mark.
- Buttons no longer move when pressed, and the question dock's focus ring is never cut off by scrolling.
- Work set to an account a host does not have, as a setting copied from another host can be, runs on the provider's own login there.
- Saving another host's thread for offline reading no longer stalls the window on a very long thread.
- The phone's terminal keys open where the keyboard was, at its height.

## Downloads

Choose the installer matching your OS and CPU: macOS arm64 (Apple Silicon), macOS x64 (Intel), or Linux x64 or arm64 (.deb, .rpm, AppImage or ZIP). SHA256SUMS files accompany the downloads.

## Known limitations

macOS builds update themselves; Linux installs outside a package manager update by hand. Windows releases are not available yet. Agent providers require their own installation and authentication.
