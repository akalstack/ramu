# Ramu v0.1.0-alpha.18

## Added

- Background service, optional: **Settings → Background → Keep running when Ramu closes** is on by default. Turned off, the service runs only while Ramu is open, and quitting Ramu stops it (running threads stop, schedules wait, and paired devices can't connect until you open Ramu again). **Start at login** needs it on. See [Background work](https://github.com/akalstack/ramu/blob/main/docs/guide/background-work.md).
- Reload from the command palette (Cmd/Ctrl+Shift+P, or `>` in Cmd/Ctrl+P): **Reload window and background service**, and **Restart background service**, which restarts only the service while the window stays and reconnects. Both ask first, since restarting stops running agents.

## Downloads

Choose the installer matching your OS and CPU: macOS arm64 (Apple Silicon), macOS x64 (Intel), or Linux x64 or arm64 (.deb, .rpm, AppImage or ZIP). SHA256SUMS files accompany the downloads.

## Known limitations

Desktop alpha. macOS builds update themselves; Linux installs outside a package manager update by hand. Windows releases are not available yet. Agent providers require their own installation and authentication. Ramu Link traffic passes through Cloudflare; every call still needs a paired device.
