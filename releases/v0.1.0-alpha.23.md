# Ramu v0.1.0-alpha.23

## Changed

- Threads in the same checkout work at the same time. Each thread's changes show only what it wrote; what another thread, you, or something else changed meanwhile shows apart and is never undone or committed with it. Claude Code's commands take turns so each command's writes have one author, a commit leaves other threads' files unticked, and switching branches can wait for the threads there to finish.
- Phone pairing says why it fails and what to turn on, and the Connect step explains the QR code and the Ramu account plainly.
- Hosts and paired phones or computers can be renamed, each with a way back to its own name.
- Restarting the background service reads as **Restarting…** and reconnects at once, **Restart service** replaces Stop, and a downloaded update installs itself once nothing is running and you step away.
- Markdown reads the same everywhere: chat, files, pull requests and summaries share one type scale on the desktop and the phone. The phone follows its Text size setting and keeps only the native selection menu, which clears when you tap elsewhere.
- The desktop starts new threads queued for an offline host once it is back, and sends queued messages after a restart.
- Terminals copy a command with its output, and copy and paste work on every platform, including the phone.
- The folder picker reaches any folder the host can read, with drives and places listed first.
- Phone Settings stays open when the host runs another Ramu version, and suggested next messages match the message box's other chips.
- Toasts no longer cover the notifications and resources panels.

## Downloads

Choose the installer matching your OS and CPU: macOS arm64 (Apple Silicon), macOS x64 (Intel), or Linux x64 or arm64 (.deb, .rpm, AppImage or ZIP). SHA256SUMS files accompany the downloads.

## Known limitations

Desktop alpha. macOS builds update themselves; Linux installs outside a package manager update by hand. Windows releases are not available yet. Agent providers require their own installation and authentication. Ramu Link traffic passes through Cloudflare; every call still needs a paired device.
