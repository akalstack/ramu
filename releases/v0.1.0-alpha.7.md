# Ramu v0.1.0-alpha.7

## Added

- Terminal: select lines and click **Add to chat** in the terminal's corner, or right-click and choose **Add selection to chat**, to show an agent what the terminal printed. With nothing selected, **Add screen to chat** takes the rows on screen. The output waits above the message box as a chip naming the terminal and its lines. Click it to check the text, or × to take it off. It goes to the agent with your next message, and you can send it without typing anything. A project's own terminal starts **New chat** with the output in the box.
- Agents: agents can read your terminals in the thread themselves, so "fix the error in my terminal" works without pasting. They read the recent output as plain text, never type into your terminals, and values that look like secrets are redacted.

## Downloads

Choose the installer matching your OS and CPU: macOS arm64 (Apple Silicon), macOS x64 (Intel), or Linux x64 or arm64 (.deb, .rpm, AppImage or ZIP). SHA256SUMS files accompany the downloads.

## Known limitations

Desktop alpha. Updates are installed by hand. Windows releases are not available yet. Agent providers require their own installation and authentication.
