# Ramu v0.1.0-alpha.14

## Added

- Cards in a thread: for a quick choice, a short form, a confirmation or a status summary, the agent shows a card drawn with Ramu's own buttons, fields and lists, on the desktop and the phone, instead of building an artifact. What you enter stays on your device until you press a button, and the press reaches the agent as your message. Cards run no code. See [Cards in a thread](https://github.com/akalstack/ramu/blob/main/docs/guide/working-with-agents.md#cards-in-a-thread).
- Card artifacts: a tracker, log, checklist or sign-up list can be kept as a new artifact kind, **Card**. It opens without a frame, natively on the phone too, and its buttons save and remove entries straight away with no model call. **Keep as artifact** on a card in a thread asks the agent to make one.
- Suggested next message: after a turn, the empty message box shows a likely next message. **Tab** uses it and **Escape** hides it, with up to two alternatives as chips; on the phone they are chips above the box. It is made only for a thread you have open. **Settings → Threads → Suggest next message** turns it off.
- New projects go where you keep projects: the folder you last chose, else the one holding most of your projects, else a projects folder you already have, else a new `~/Projects`, never your home folder. When an agent creates a project, its approval card shows the folder with **Change…**, on the desktop and the phone.
- Claude models with fast mode (Opus and Fable) offer **Standard** and **Fast** in the model picker, as Codex does.
- Pull request links open in Ramu's own Pull requests page on the desktop when the host lists that pull request. **Settings → Browser → Pull request links** switches to always opening the service, and a link's right-click menu offers the other way.
- The main window shows the Ramu mark from its first frame, and the mark's dot breathes while a start is slow, so a long first start no longer looks like a blank window.

## Fixed

- Starting: a slow start could end with "ERR_FAILED (-2) loading index.html". Closing the small "Starting Ramu" window made the app begin quitting before its main window existed.
- Cursor: opening Ramu no longer opens Cursor's sign-in page by itself. Listing Cursor's models at launch asked its command-line tool to sign in.
- Remote access: `cloudflared`, `tailscale` and `ngrok` are found where they are installed (Homebrew's and your own bin folders), not only on the PATH the app started with, and the tunnel starts by itself once a missing tool is installed. Settings no longer says "Then save again" with nothing to save.
- Ramu Link: Settings no longer says the link can't be reached when the only problem is that `cloudflared` is missing.
- Remote access: a phone or tablet is no longer offered the **Agents** permission, which is for another computer's agents.
- New thread: the host, project and checkout chips above the message box are back at the left, and the settings button in the tray is round like the controls beside it.

## Downloads

Choose the installer matching your OS and CPU: macOS arm64 (Apple Silicon), macOS x64 (Intel), or Linux x64 or arm64 (.deb, .rpm, AppImage or ZIP). SHA256SUMS files accompany the downloads.

## Known limitations

Desktop alpha. macOS builds update themselves; Linux installs outside a package manager update by hand. Windows releases are not available yet. Agent providers require their own installation and authentication. Ramu Link traffic passes through Cloudflare; every call still needs a paired device.
