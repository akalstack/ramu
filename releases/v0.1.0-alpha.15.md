# Ramu v0.1.0-alpha.15

## Added

- Terminal command: **Install** next to **Terminal command** in **Settings → Background & updates** (also offered in setup) puts a `ramu` command on this computer's PATH. It runs the command line that ships inside the app, so it always matches the app, and it follows the app when it moves. It is not offered for an AppImage, a Mac app opened straight from Downloads, or Windows. See [Hosts and remote access](https://github.com/akalstack/ramu/blob/main/docs/guide/remote-hosts.md).
- Run the server without the app: the workspace server and its `ramu` CLI are on npm as `@akalstack/ramu`, for Node.js 26 (`npx --allow-scripts=node-pty,esbuild @akalstack/ramu serve`, or `npm install --global` before `ramu up`). A host installed from npm says which command brings it a new release. See [Headless server](https://github.com/akalstack/ramu/blob/main/docs/guide/remote-hosts.md#headless-server).
- Plugins can sign in with the service's own account, with no key or client to paste: **Install** opens the service's sign-in page, and the card shows **Sign in** and **Sign out**. The Higgsfield plugin makes video this way, on your Higgsfield account. Video, speech, music, sound effects and 3D models from a plugin's service ask before the first call in a thread, since they spend the account's credits.
- One Gemini key for both: a Gemini key saved under **Media** fills Antigravity's **Gemini API key**, and a key Antigravity signs in with also makes Gemini's video, speech and music.
- Setup asks a model and effort for each agent that is on, starting with the one new threads use, each with its recommended choice selected.

## Fixed

- Phone: a host that removed this phone's pairing now says the pairing was revoked and to pair again, instead of trying its other addresses.
- Antigravity is no longer started at launch without a login, which opened Google's sign-in page.

## Downloads

Choose the installer matching your OS and CPU: macOS arm64 (Apple Silicon), macOS x64 (Intel), or Linux x64 or arm64 (.deb, .rpm, AppImage or ZIP). SHA256SUMS files accompany the downloads.

## Known limitations

Desktop alpha. macOS builds update themselves; Linux installs outside a package manager update by hand. Windows releases are not available yet. Agent providers require their own installation and authentication. Ramu Link traffic passes through Cloudflare; every call still needs a paired device.
