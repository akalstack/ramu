# Ramu v1.1.0-beta.2

## Added

- **Install as app:** an artifact's menu on the desktop adds it to this computer's apps, named after the artifact with its emoji as the icon: under **Applications › Ramu Apps** and Launchpad on macOS, and in the applications menu on Linux. Opening it shows that artifact alone in a window of its own, always at its newest version, with its records, AI and live updates, and a thread it starts opens in Ramu's main window. Nothing is published to do this. **Open in its own window** opens the same window without installing, and **Uninstall app** removes it.
- **App icon…** gives an installed artifact a picture instead of its emoji: choose one of your own, cropped to a square, or **Make with AI** from the artifact's name or a few words you type, with the image generation chosen in Settings → Models → Abilities. The picture is kept with the artifact on its host, so every desktop that installs it shows the same icon, and a new name, emoji or picture updates the installed app.

## Changed

- **Publish to the web** deploys a plain one-file site again. Installing an artifact as an app now happens in Ramu itself, so publishing stays optional.
- On the phone, inline code has rounded corners, and code that wraps onto the next line no longer touches the line above.
- On the phone, the host's permissions read **What this phone can do on** the host, with a line saying what each one allows from the phone.
- The phone's host sheet has **Manage hosts**, and pickers on the phone mark the chosen option with a check on the left.

## Downloads

Choose the installer matching your OS and CPU: macOS arm64 (Apple Silicon), macOS x64 (Intel), or Linux x64 or arm64 (.deb, .rpm, AppImage or ZIP). SHA256SUMS files accompany the downloads.

## Known limitations

Desktop beta. macOS builds update themselves; Linux installs outside a package manager update by hand. Windows releases are not available yet. Agent providers require their own installation and authentication. Ramu Link traffic passes through Cloudflare; every call still needs a paired device. On macOS the Dock shows Ramu's icon while an installed artifact's window is open.
