# Ramu v1.1.0-beta.9

## Added

- **Restart another host's service from your device.** With another host selected, **Settings → Background → Restart service** restarts that host's background service and waits until it answers again. It is offered when the host's own system starts the service again (it starts at login, or runs as `ramu up`); a host started some other way says to restart it on that computer instead.
- **Pictures from tool calls show on the phone.** Opening a tool row shows the images the call returned, such as a browser screenshot or a generated image, and reading an image file shows that picture, as on the desktop. An image the agent names by its path on the host loads from the host instead of showing blank.

## Changed

- **Keep host awake keeps a laptop awake while agents work.** Its recommended choice, now **Plugged in, or while agents work**, also keeps the host awake on battery while threads run and for a minute after, so a run you left going is not cut off by sleep; otherwise a laptop on battery sleeps as usual. The display still dims and turns off.
- **One Live Activity, started by the open app.** The host no longer starts one while Ramu is closed: an activity started that way could stay frozen on the Lock Screen when iOS did not hand Ramu what it needs to update it. Ramu keeps a single activity, taking over or ending any other that appears.
- **The Live Activity shows Ramu's mark** in white, with the state's color on the count and status beside it. The Dynamic Island shows how long the work has run, the Lock Screen's timer sits at the right edge, and the lines under the headline align with it.
- **On the desktop a running label pulses lighter**, as on the phone, instead of dimming, and a finished tool no longer sweeps a highlight across its label.
- **The phone's terminal cursor pad** is a plain glass panel, and the arrow being sent lights up in the accent color.
- **Swiping back from a thread on the iPhone** fades the top bar out where it is, instead of sliding the back button away with the thread.

## Fixed

- **Stopping or restarting the background service no longer fails the threads it was running.** An agent the shutdown ended showed **The agent stopped with an error** and its goal was blocked, so the restart did not resume it. It now picks up where it left off.
- **The Live Activity no longer says all work is done while a thread runs.** A steer or the moment between two turns is not the end of the work: the activity, on the phone and from the host, waits a few seconds of nothing running first.
- A Live Activity swiped away, or ended without Ramu asking, comes back with the next work, instead of staying away until Live Activities are turned off and on.
- **Resume** on the phone restarts a goal stopped at its turn limit, with its count from zero, and a blocked goal, instead of doing nothing.
- **Answer** in the phone's Inbox brings up the question when it had not reached the phone yet, instead of saying it is still loading.
- Holding the keyboard's delete key in the phone's terminal keeps deleting.
- A note that a background command finished or was stopped names the command by its first line, on the phone and the desktop, instead of printing a long script across the thread.
- The phone's clock and battery stay readable on a theme whose colors are dark under light appearance, on iPhone and Android.
- The Live Activity's symbols draw at their own size in the Dynamic Island, instead of a large symbol cut off in its corner.
