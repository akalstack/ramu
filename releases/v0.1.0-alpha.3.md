# Ramu v0.1.0-alpha.3

## New

- Ramu updates itself on macOS. **Auto-update Ramu** is on by default: it downloads a new release a day after it is published, checks it and installs it when you restart Ramu. Alpha builds follow every newer release, beta builds follow beta and stable releases, and stable builds follow stable releases only.

Install this release by hand once; Ramu installs later releases itself. If you used an earlier alpha, turn on **Settings → System → Auto-update Ramu**.

## Downloads

Choose the installer matching your OS and CPU: macOS arm64 (Apple Silicon), macOS x64 (Intel), or Linux x64 or arm64 (.deb, .rpm, AppImage or ZIP). SHA256SUMS files accompany the downloads.

## Known limitations

Desktop alpha. Linux installs are told about new releases and installed by hand. Windows releases are not available yet. Agent providers require their own installation and authentication.
