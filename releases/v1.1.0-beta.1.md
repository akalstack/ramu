# Ramu v1.1.0-beta.1

Ramu moves from alpha to beta, and the desktop app, the iPhone app and the Android app now share one version: 1.1.0.

## Added

- **Ship:** ask a thread's agent to ship and it carries the change to the project's finish line without you pressing each step. It fixes and pushes failing checks, drafts replies for each review round, and stops at **Pull request**, **Ready for review**, **Merged**, **Preview deploy** or **Live in production**. Pick the finish line under **Ship** in a project's **Live app** sheet on the desktop or the phone. Approving, merging and production deploys still ask you. A team can cap it in `ramu.json` on the default branch, which an agent can't change.
- Inbox's **Done** (formerly **Completed**) lists what Ship did without asking, such as a check fix it pushed, with **Undo**, which pushes a revert. Pull requests with drafted replies or a drafted review lead with them in the Brief, such as "3 replies drafted", with **Review and send**.
- New projects: **Agent recommends** a stack and starts without a framework unless the app needs sign-in, stored data, many pages, or is a phone or desktop app. Pick from Rust, Swift, Tauri, Electron, Flutter, Vite + Vue, Nuxt, Vite with no framework and Node with no framework, as well as the stacks Ramu already had, or type any framework under **Other framework…**. The agent then looks up its official create command and shows you the commands and their sources before anything runs.

- An artifact published to the web can be installed as an app: Chrome and Edge offer **Install**, and Safari **Add to Dock** or **Add to Home Screen**. It opens in its own window with the artifact's emoji as its icon and works offline. **Update live site** reaches installed copies, which offer **Reload** once the new version is ready.

## Changed

- Replies read steadily. Text arrives a paragraph, list or code block at a time, each new block fading in once, for every provider, on the desktop and the phone, instead of word by word.
- Tool groups open and close at once and stay put while new calls arrive, so the reply below them no longer moves while you read.
- A failed command says why without opening it: its exit code and last lines show under the row, and a closed group names its latest failure.
- Editing a queued or steering message keeps its place in the queue. It is edited where it is, held until you save, on the desktop and the phone.
- A new thread on a model at its usage limit says, before you send, which model it will start on instead.
- What a pull, merge or rebase brings in while an agent works is no longer counted as the agent's edits; changes it makes on top of pulled files still are.
- A thread marked done stops waiting on a usage limit, so it no longer shows the limit tray or its goal, and never resumes by itself at the reset.
- The desktop limit tray shows its whole message, and only the tray offers Try again while a limit holds.
- Pull requests refresh faster and cost fewer GitHub calls. A branch's pull request is read straight from GitHub with your `gh` sign-in instead of starting `gh` each time, and an unchanged one costs no rate limit; every view shares one read for a few seconds; a push or `gh pr` command the agent runs updates it on the desktop and the phone at once; coming back to the app reads it again; and the desktop opens on the last one it saw, also after a restart.
- **Live pull request updates** (Settings → Git): reviews, finished checks and merges show on the desktop and the phone the moment they happen, and a watching thread hears of a finished check at once. Install the **Ramu GitHub App** ([Ramu by Akalstack](https://github.com/apps/ramu-by-akalstack)) on a repository or organization and its updates arrive through Ramu Link, with no admin rights or public address needed; where it is not installed, Ramu adds a webhook instead. Settings shows each repository's source, or what is missing.
- The service downloads an update only where an installed app can install it, and verifies a downloaded update without holding up its start.
- Arch Linux installs Ramu from the AUR with `yay -S ramu-bin` (or any AUR helper), which brings each new release.

## Downloads

Choose the installer matching your OS and CPU: macOS arm64 (Apple Silicon), macOS x64 (Intel), or Linux x64 or arm64 (.deb, .rpm, AppImage or ZIP). SHA256SUMS files accompany the downloads.

## Known limitations

Desktop beta. macOS builds update themselves; Linux installs outside a package manager update by hand. Windows releases are not available yet. Agent providers require their own installation and authentication. Ramu Link traffic passes through Cloudflare; every call still needs a paired device.
