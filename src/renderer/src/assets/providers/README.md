# Provider logos

Local copies of the actual provider marks, used to identify integrations. Trademarks belong to their respective owners.

- **Claude**: [Simple Icons Claude SVG](https://github.com/simple-icons/simple-icons/blob/develop/icons/claude.svg), an exact brand mark distributed under CC0. The original branding is Anthropic's.
- **Codex / OpenAI**: [OpenCode's OpenAI provider asset](https://github.com/anomalyco/opencode/blob/dev/packages/ui/src/assets/icons/provider/openai.svg), distributed with OpenCode under MIT.
- **OpenCode**: [OpenCode's official square logo](https://github.com/anomalyco/opencode/blob/dev/packages/console/app/src/asset/brand/opencode-logo-dark-square.svg), MIT.
- **Cursor**: `General Logos/Cube/SVG/CUBE_2D_DARK.svg` from the official [Cursor brand asset archive](https://cursor.com/brand).
- **Antigravity**: full-color icon from the official [Google Antigravity press assets](https://antigravity.google/press).

The original SVG geometry is retained. Claude, OpenAI, and Cursor use CSS masks to follow the UI color; OpenCode and Antigravity retain their asset colors.
